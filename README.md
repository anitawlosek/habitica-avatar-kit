# Habitica Avatar Kit

Avatar customization tool for Habitica users. Preview, customize, and export your Habitica avatar with an intuitive interface.

## Live

🌐 [habitica-avatar-kit-dev](https://anitawlosek.github.io/habitica-avatar-kit-dev)

## Features

- 🎨 **Avatar Customization** - Modify appearance, gear, pets, mounts, and backgrounds
- 📱 **Mobile Responsive** - Works seamlessly on desktop and mobile devices
- 💾 **Save & Load** - Save avatar configurations and sync with your Habitica account
- 📸 **Export Images** - Download or share your avatar as PNG images
- 🔍 **Item Browser** - Explore and equip items from the complete Habitica catalog

## Custom Libraries

This project uses custom-built libraries specifically designed for Habitica avatar functionality:

### 🎭 [habitica-avatar-react](https://github.com/anitawlosek/habitica-avatar-react)
React components for rendering Habitica avatars with full customization support. Handles sprite positioning, layering, and visual effects.

### 📋 [habitica-avatar-manifest](https://github.com/anitawlosek/habitica-avatar-manifest)
Comprehensive catalog of all Habitica items, sprites, and metadata. Provides up-to-date item definitions and asset references.
